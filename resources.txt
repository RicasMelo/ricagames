Resources
=========

This file documents missing resources, expected paths, recommended resolutions,
and whether each asset should use a transparent background.

When you add a new visual feature, update this file first. It acts as the
asset contract between the code and the art folders.

Every expected PNG should have a matching TXT file beside it with the same base
name. Example: main-lobby-tower.png uses main-lobby-tower.txt.

- File type: PNG or WebP

- Recommended: 1600 x 800 px

- File type: PNG or WebP

assets/symbols/glowing-runes.png

- File type: PNG

assets/portraits/default-character.png
- Recommended: 512 x 512 px
- Background: transparent
- File type: PNG

assets/events/glass-saint.png
- Recommended: 1024 x 1024 px
- Background: transparent preferred
- File type: PNG or WebP

assets/audio/main-lobby-ambience.mp3
- Recommended: looping MP3, 128-192 kbps
- Background: not applicable
- File type: MP3

sprites/player/{classId}/{skinId}/front.png
- Expected: 128 x 128 px
- Background: transparent
- File type: PNG
- Notes: character centered, feet near bottom edge with 8-12 px padding.

sprites/player/{classId}/{skinId}/back.png
- Expected: 128 x 128 px
- Background: transparent
- File type: PNG
- Notes: same scale and anchor position as front.png.

sprites/player/{classId}/{skinId}/profile.png
- Expected: 96 x 96 px
- Background: transparent
- File type: PNG
- Notes: head/shoulders crop with face centered.

sprites/player/{classId}/{skinId}/icon.png
- Optional: 64 x 64 px
- Background: transparent
- File type: PNG
- Notes: readable at small UI size.


Player Sprite Naming Rules
--------------------------

- Use lowercase folder and file names.
- Use underscores for multiple words: iron_armor, blue_robes, forest_cloak.
- Do not use spaces in file or folder names.
- Keep every skin folder complete: front.png, back.png, and profile.png should all exist.
- The default skin should always be named default.

Player data fields:

character.classId:
- Matches the class folder.
- Example: warrior

character.spriteSkin:
- Matches the skin folder.
- Example: default

character.spriteView:
- Usually chosen by the screen, not saved permanently.
- Examples: front, back, profile

Example player sprite data:

{
  "classId": "warrior",
  "spriteSkin": "default"
}

Then the lobby can load:
- sprites/player/warrior/default/front.png

And battles can load:
- sprites/player/warrior/default/back.png
